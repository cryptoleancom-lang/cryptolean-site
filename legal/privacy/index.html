// Privacy

No accounts, no analytics, no cookies.

Published 2026-08-06Last updated 2026-08-06Applies to cryptolean.com

Reading this site anonymously is the default and there is no version of it that is not anonymous. This notice explains the small amount that is left.

What this site collects

Nothing that identifies you, and nothing you do not send. The whole site is static files. There is no database behind it, no analytics script, no advertising or social pixel, no embedded video, no externally hosted font and no third-party JavaScript of any kind. Charts are drawn in your browser from files served with the page, so reading a chart makes no request to anyone else.

There are no accounts. Nothing on this site requires one, nothing asks you to create one, and there is no profile, history or watch record held by us or on a server for you.

Stored on your device

A short list of keys in browser storage, written only when you take an action, readable and clearable by you at any time, and none is a cookie — nothing here is sent to a server with a request.

KeyWritten whenWhy
cl:themeWhen you switch to the light themeSo the choice survives a reload. Cleared when you switch back to dark.
cl:favouritesWhen you star a chartA list of chart slugs, so the rail and device-local watchlist can show them. Never leaves the browser.
cl:saved-views:v1When you press Save view on a chartThe chart path, analytical URL state, name and save time. Never leaves the browser.

Clearing site data in your browser removes all of them, and the site works exactly as before with them gone. Chart settings — the ranges and toggles you choose — live in the page URL rather than in storage, which is what makes a view shareable by copying the address.

Who else can see anything

WhoWhat they see
Static hostServes the files. Keeps standard web-server access logs — IP address, time, page requested, browser string — for operational and security purposes.
Email providerReceives and stores messages you choose to send to the contact address, as any mailbox does. Nothing on this site writes to it.

That is the complete list. Access logs are a property of serving a web page at all rather than a choice made here, and they are not joined to anything, analysed for behaviour, or used to build a profile.

If you write to us

The contact form has no server behind it: it composes a message and hands it to your own mail application, and the page tells you so rather than showing a confirmation it cannot justify. Whatever you then send arrives as an ordinary email and is kept in a mailbox for as long as the correspondence is useful.

It is not added to a mailing list, not enriched against a data broker, not fed to a CRM and not passed to anyone. There is no marketing list to be added to. Ask for a message to be deleted and it is deleted.

Your rights

The practical answer is that there is almost nothing to exercise them against: no account to access, no profile to correct, no behavioural record to erase. Where you have sent an email, you can ask for a copy of what is held or ask for it to be deleted, and either is done promptly and without conditions.

Requests go to the address on the contact page. No identity documents are asked for, because nothing here is sensitive enough to justify collecting more data in order to protect less.

Children

This is a research site about financial markets. It is not intended for children, and nothing on it is designed for or directed at them.

Changes

If the site starts doing something this notice does not describe — analytics, accounts, payments, an embed — the notice changes in the same release, and the “last updated” date at the top moves. There is no version of that where the practice changes first.
