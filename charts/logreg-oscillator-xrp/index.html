Chart description

logreg-v2 · val-v1 · The gap is log(price) minus log(fair value) against the expanding fit; the percentile is where that gap ranks against every EARLIER day, and only against earlier days. Both are computable on the day they refer to, which the conventional full-sample version of this chart is not.

How to read it

Every value plotted for a past date could have been computed on that date.
