# cryptolean-site

Built output for **cryptolean.com**. Generated, not authored — every file here is
produced by the pipeline in the private `Cryptolean` repository and force-pushed
on each build.

Public because the site is public: this is the same HTML, CSS and JSON any visitor
downloads. The risk model, the fetch layer, the resolution database and the raw
data are not here.

Do not edit anything in this repository. It is overwritten on every deploy.
