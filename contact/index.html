// What happens to what you send

Nothing is stored on this site.

There is no database here and no analytics — the whole site is static files. A message becomes an email in an inbox and nothing else: it is not added to a marketing list, not enriched against a third party, and not passed on. Ask for it to be deleted and it is deleted. The full position is in the privacy notice, which is short for the same reason.
