// Methodology · stable

Stablecoin supply transformations.

Current definition stable-v1. Charts stamped with it were computed by src/metrics/stablecoins.py, and every value plotted for a past date could have been computed on that date.

Definition and failure modes

The input is DefiLlama's source-native daily USD aggregate for all tracked USD-pegged stablecoins. A change in that aggregate is useful as a liquidity measure, but it is not a pure mint/burn ledger: peg deviations, coverage changes and upstream revisions can also move the USD total.
